# 🏨 Hostel Management System (Django)

A full-featured Hostel Management System built with Django to manage students, rooms, departments, and hostel operations efficiently.

---

## 📌 Project Overview

This system is designed to help universities or institutions manage hostel activities such as:

* Student registration
* Room allocation
* Department management
* Faculty management
* Search and filtering system

---

## 🚀 Features

* ✅ Add, update, delete students
* ✅ Assign students to rooms
* ✅ Manage departments and faculties
* ✅ Search functionality (Django Q filters)
* ✅ Pagination system
* ✅ Clean and responsive UI
* ✅ Admin panel support

---

## ⚙️ Installation Guide

### 1️⃣ Clone the repository

```
git clone https://github.com/your-username/Hostel_MGM_Django.git
cd Hostel_MGM_Django
```

---

### 2️⃣ Create virtual environment

```
python -m venv venv
```

Activate:

* Windows:

```
venv\Scripts\activate
```

* Linux/Mac:

```
source venv/bin/activate
```

---

### 3️⃣ Install dependencies

```
pip install -r requirements.txt
```

---

### 4️⃣ Run migrations

```
python manage.py migrate
```

---

### 5️⃣ Run server

```
python manage.py runserver
```

Open in browser:

```
http://127.0.0.1:8000/
```

---

## 🔐 Admin Panel

Create superuser:

```
python manage.py createsuperuser
```

Login:

```
http://127.0.0.1:8000/
```
